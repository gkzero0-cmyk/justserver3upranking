# Applicant Detail and Deadline Spec

## Goal
신청자 상세 보기의 신청 댓글 파싱 정확도를 높이고, 신청 댓글 원문과 SOOP 방송국 프로필 사진을 보여주며, 메인 제목 옆에 2026-09-20 접수 마감 D-day를 한국시간 기준으로 표시한다.

## Requirements
- 상세 보기의 `이름`, `즐겨찾기수`, `하고싶은말`, `입주비 동의 여부`를 가능한 한 신청 댓글 양식에 맞게 각각 분리한다.
- 이모지/불릿이 붙은 라벨과 `즐겨찾기수`, `즐찾`, `팔로워`, `팔로우 수`, `입주비동의여부` 같은 표기 변형을 인식한다.
- `💙이름 / 💙숫자명 / 💙메시지 / 💙입주비 동의`처럼 라벨 없이 여러 줄로 작성된 신청서도 분리한다.
- 기존 `/` 구분 양식은 계속 지원한다.
- SOOP 현재 즐겨찾기 수는 방송국 API의 실제 응답 구조인 `station.upd.fan_cnt`를 우선 사용하고, 없을 때 신청 댓글의 수치를 사용한다.
- SOOP 방송국 `profile_image`는 상세 상단 **신청자 이름 바로 왼쪽**에 작은 원형 프로필 사진으로 표시한다.
- 상세 화면 오른쪽 큰 이미지는 기존처럼 **신청 댓글 첨부 이미지**만 표시하며 방송국 프로필 사진으로 대체하지 않는다.
- 상세 보기 안에 `신청 댓글 원문 보기` 버튼을 추가하고, 클릭하면 원문 전체가 펼쳐지고 다시 접을 수 있어야 한다.
- API 응답에 신청 댓글 원문과 방송국 프로필 이미지 URL을 포함한다.
- 메인 제목 옆에 접수 마감일 `2026-09-20` 기준 D-day를 표시한다.
- D-day 계산은 `Asia/Seoul` 달력 날짜 기준으로 하며, 마감 전은 `D-N`, 당일은 `D-DAY`, 이후는 `D+N`으로 표시한다.
- 기존 1초 자동 갱신, 랭킹, 즐겨찾기, 신규 신청자, 댓글 더보기 기능을 깨뜨리지 않는다.
