# 마병대 4 실시간 UP 랭킹 설계

## 목표
SOOP 게시글 `devil0108/206507027`의 공개 댓글을 1초 주기로 갱신해 UP 기준 랭킹으로 보여주는 독립 사이트를 만든다.

## 핵심 기능
- 사이트명: `마병대 4 실시간 UP 랭킹`
- SOOP 원문 댓글 전체 수집 및 UP 높은 순 랭킹
- UP순/최신순/오래된순 정렬, 검색, 100위 커트라인
- 작성자 프로필 아이콘 및 방송국 링크, 신청 댓글 바로가기
- 한국시간 기준 오늘 새 신청자 수
- 브라우저 로컬 즐겨찾기
- 병사/간부/미분류 자동 분류와 사용자 수동 덮어쓰기
- 프리패스/프리패스 제외/미지정 상태 지정
- 분류/프리패스/즐겨찾기 전용 필터
- UP 순위 변동 시 `18위 → 12위 ▲6` 또는 `7위 → 11위 ▼4` 표시
- 개인 설정 JSON 내보내기/불러오기

## 구조
Vercel 정적 프론트엔드 + `/api/comments` 서버리스 함수로 구성한다. 프론트엔드는 댓글 원본 데이터와 사용자 로컬 메타데이터를 분리하고, 댓글 고유키 기준으로 즐겨찾기/수동 분류/프리패스 상태를 합성한다. SOOP 호출 실패 시 마지막 화면은 유지하고 오류 상태만 표시한다.

## 저장 정책
- 즐겨찾기, 수동 분류, 프리패스 상태는 `localStorage`에 저장한다.
- 민감정보나 인증정보는 저장하지 않는다.
- 자동 분류는 댓글 텍스트의 `간부`, `병사` 키워드를 사용하되 수동 지정값이 항상 우선한다.

## 배포
기존 `justserver-up-ranking` 사이트는 수정하지 않는다. 동일 GitHub 저장소 안에 `mabyeongdae4-up-ranking/` 독립 루트를 추가하고 Vercel에서 별도 프로젝트/루트 디렉터리로 배포한다.
